# Repository Security Notice

This is a public documentation repository. It must never contain:

- credentials or passwords;
- wallet seed phrases or recovery phrases;
- private or signing keys;
- API keys or access tokens;
- environment files;
- personal confidential information;
- product source code.

The frozen publication release is stored under `releases/v1.0-R1/`. Report a suspected disclosure privately to the repository owner; do not open a public issue containing the sensitive value.
